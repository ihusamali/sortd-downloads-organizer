# Security Policy

## Supported versions

Only the latest tagged release is supported with security fixes.

## Reporting a vulnerability

Please do not post credentials, private documents, or exploit details in a public issue. Report suspected vulnerabilities through GitHub's private vulnerability reporting for this repository. Include the affected version, impact, and steps to reproduce when safe to share.
